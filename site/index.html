Tasks

An autonomous software pipeline with a human in the loop. Tasks turns a GitHub issue tracker into shipped pull requests by orchestrating coding agents — you review, it works.

Warning

Running Tasks is risky. It runs autonomous agents, without permission prompts, holding credentials that spend your Anthropic API budget and push to your GitHub repositories. Research how it works before you run it, and pay attention while it runs.

Scouting

Scouts run in parallel, each in a throwaway VM. A Scout explores the codebase and writes a spec — a text document saying what to build and how. The spec is the deliverable; the Scout's code is discarded.

Building

Approved specs go to a Builder, one build at a time. A Builder starts from a fresh branch and the spec alone — never Scout code — implements it, and opens a pull request. The issue closes only once the work reaches trunk: done means shipped.

Orchestration

Between the two sits a review, by you or by the orchestrator — an agent that reads everything owed a decision and acts: queueing work, reviewing specs, dispatching and landing builds. What it may do is a nine-capability charter you control, and every act lands in a decisions ledger with its rationale, open to audit.
